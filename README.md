# -Cover-Next
ปลั๊กอินเว็บสยามบิท เพื่อให้การท่องเว็บสนุกมากอย่างขึ้น ใช้งานสะดวกและง่ายกว่าเดิม   แสดงหน้าปกในรายการได้ แม้ลิงค์จะไม่ใช่ลิงค์รูปภาพโดยตรง  รองรับแคชสำหรับการดึง url ของรูปภาพหน้าปก
เมื่อเอาเมาส์ไปวางที่รูปปกหรือชื่อรายการ จะแสดงรูปขนากใหญ่
 รองรับเมื่อรูปนั้นโหลดไม่ได้ ไม่มีรูป
 รองรับการยกเว้นรูปเฉพาะหมวดหมู่ที่ไม่ชอบ
 สีปุ่มจะเปลี่ยนไปเมื่อไฟล์เกินขนาด 10 GB
 ระบบออโต้ขอบคุณ ทั้งในหน้ารายการและหน้ารายละเอียดไฟล์
 รองรับอัลบั้ม โดยคลิกที่รูปปก
 รองรับสีชื่อรายการที่ดาวน์โหลดไปแล้ว
 ปุ่มดาวน์โหลดที่อยู่ในหน้ารายการ แม้จะไม่ใช่สมาชิก VIP
 ลบโฆษณา ลบ โลโก้

การใช้งาน
หลังจากติดตั้งแล้ว คุณสามารถตั้งค่าได้ที่รูปฟันเฟืองมุมล่างขวาจอบนหน้าเว็บบิท
หากคุณต้องการอัปเดตสคริปต์ ให้คุณกดติดตั้งซ้ำอีกครั้ง
